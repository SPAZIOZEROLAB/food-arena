# Reproduce the budget contract tests

Place this folder at `docs/tests-budget-contract` in the Food Arena repository. It tests the actual repository sources, `contracts/FoodArenaBudgetFuji.sol` and `app/budget-abi.ts`, using relative paths. No duplicated Solidity fixture is used.

With Node.js 20 or later:

```sh
cd docs/tests-budget-contract
npm ci --ignore-scripts --no-audit --no-fund
npm test
```

The installation downloads the pinned development dependencies. The test itself runs entirely in process with Ganache; it opens no RPC port, reads no `.env` file, uses no external wallet, and sends no Fuji or mainnet transaction. Test accounts are generated by Ganache and are never printed. All generated files go to `.test-output/`: compiled artifact, temporary runtime module and machine-readable `test-results.json`. These outputs and `node_modules` are ignored by Git.

The 13 test groups check:

- compilation, ABI return fields/event indexing and the EIP-712 domain;
- merchant signature ownership, domain binding, strict ECDSA and configuration replay;
- gifted deposits without donor or relayer withdrawal authority;
- signed price/terms/merchant binding and protection from another merchant occupying an order ID;
- 12 simultaneous holds with budget for exactly 5;
- preserved reserved/spent value and the beneficiary fixed at hold time;
- rejection of a previously signed hold after the configured beneficiary changes;
- a distinct merchant settlement authorization and single-use concurrent settlement;
- reserved funds excluded from withdrawals, signed withdrawal replay and beneficiary-only claims;
- permissionless expiry release and permanently consumed order IDs;
- per-order, lifetime and maximum-duration limits;
- reentrant or rejecting beneficiary behavior;
- refusal to deploy when a simulated chain reports Avalanche mainnet ID 43114.

Amounts use simulated native funds. Distinct test signing keys establish authorization separation; the script controls all test accounts and does not claim they represent independent businesses. Local tests do not establish the correctness of offchain meal availability or physical pickup.

Ganache may warn that the native uWS binary is unavailable on a newer Node.js build, then use its JavaScript implementation. The tests should still finish with `"passed":true` and `"testCount":13`. Any assertion failure exits with a nonzero status.

The lockfile preserves `fsevents` as an optional dependency of Ganache's bundled Chokidar, as declared by Chokidar. This allows `npm ci` to skip the macOS-only package on Windows/Linux. Keep the committed lockfile for reproducible installation.

For a relocated test folder, an optional relative override resolves from this folder:

```sh
node test-budget.mjs --source-root ../../path-to-food-arena
```

Compiler settings: Solidity 0.8.30, optimizer enabled with 200 runs, EVM Paris. The result records the SHA-256 of the exact contract source tested and compiled runtime size. This reproducible suite is not a third-party audit.
